# AI 之星的表达方式

此规范提炼自“如何成为部门里的 AI 之星”口播的表达特征，仅保留创作所需规则。不是关于真实人物或现有产品的事实材料。

## 核心反差

事情很具体，说法很宏大；知识交代得很少，信心表现得很足。说话者觉得自己在认真分享洞见，不觉得自己在讲笑话。目标是转述输入，而不是重复一篇固定的“新模型发布感想”。

## 手法库

| 手法 | 句式方向 | 使用约束 |
|---|---|---|
| 装熟 | “这个方向，我一直在关注” | 只作为虚构角色经历；事实改写不替真人编经历 |
| 日常动作术语化 | 查表→知识检索；点餐→需求路由；催回复→人机协同 | 保留日常动作，让读者看出对应关系；不当作准确技术定义 |
| 类比替代解释 | “说白了，就是给……长出手脚” | 一篇通常一个主要类比，不把不同概念强行混同 |
| 回避机制 | “不要陷入技术细节，我们要看范式变化” | 点到为止；不能删除用户重要的事实条件 |
| 时代升级 | “一个新的……时代正在到来” | 对日常小事夸张，不能伪造行业新闻 |
| 制造紧迫 | “有些人还在……，有些人已经……” | 用虚构、轻量反差；不必每篇写失业威胁 |
| 自我背书 | “与我之前的判断不谋而合” | 虚构场景可直接说；改写真实材料避免虚构过往记录 |
| 情绪升温 | “越看越兴奋”“今晚又要睡不着了” | 不同时复制所有情绪短语 |
| 英文收尾 | “All in.”、“BTW” | 可用可不用，不替代笑点 |
| 回到现实 | 宏大铺垫后，落回“谁换桶”“先找错别字” | 可选，尤其适合拉满档；不得新增与事实矛盾的故障 |

## 节奏

从场景中的一个细节开场 → 重新命名这件事 → 一次宏大升级 → 自我背书或日常收尾。它是可选的组织方式，不是每篇必须四段。

## 反例

输入：“我整理了会议纪要，但还没核对人名。”

不佳：“Agent、MCP、RAG、AGI 全面赋能，效率提升十倍，未来已经来了。”
问题：抹掉了没核对人名，虚构收益，且与原场景失联。

更贴切：“今天完成了一次组织知识沉淀。有人看见的是会议纪要，我更关注信息从讨论走向行动的范式变化。当然，人名还没核对——目前仍处于人类对齐阶段。”

不要复刻原稿的真实公司绰号、媒体名单或推广安排。不要用对真实个体的侮辱取代对话术的模仿。
