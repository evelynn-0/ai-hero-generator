# AI Hero Generator / AI 之星转述器

**把一句普通的话，说出提前进入下一个时代的感觉。**

v0.1.0 · 中文优先 · 源码公开 · 自定义署名许可

输入一段原话或一个场景，输出一本正经的 AI 圈话术戏仿。保持具体事情，让表达从“我写了周报”升级到“个人与组织的信息接口正在被重写”。

## 怎么用

这是可由 AI 助手读取的指令包，不是独立应用。把整个 `ai-hero-generator` 文件夹提供给支持文件型 Skill 的助手，按该助手的安装方式加载；也可以提供本项目文件，让助手先读 `SKILL.md`。不需要 API 密钥或强制联网。

```text
使用 ai-hero-generator
/rewrite 我整理了会议纪要，但还没核对人名。
强度=标准；形式=短句
```

输出示例：

> 【AI 之星式戏仿｜非事实背书】
>
> 今天完成了一次组织知识沉淀。有人看见的是会议纪要，我更关注信息从讨论走向行动的范式变化。当然，人名还没核对——目前仍处于人类对齐阶段。
>
> 使用 AI Hero Generator 生成或辅助完成 · evelynn-0
> https://github.com/evelynn-0/ai-hero-generator

## 两个入口

| 入口 | 输入 | 行为 |
|---|---|---|
| `/rewrite` | 一段已经写好的话 | 保留事实、数字和立场，改变表达 |
| `/scene` | 一件事、一个场景 | 写一个明确标注的虚构发言 |

无需记住命令，也可以说“把下面这句话用 AI 之星口吻说出来”。斜杠是本 Skill 的文本约定，不会自动注册成软件按钮。

可选强度：轻度、标准、拉满。可选形式：短句、朋友圈、会议发言、口播；可以指定字数。默认交付一版成稿，不附打分、风格分析或创作教程。

## 适用边界

- 幽默来自装熟、类比、宏大叙事和自我背书，而不是辱骂个人。
- 原话改写保留“还没完成”“可能有效”等事实条件，不编造收益、经历和背书。
- 虚构场景可有虚构角色的台词，但不能冒充真实人物或制造假新闻。
- 输出默认标明戏仿并附署名；不提供不可删除水印，也不保证每次生成都同样好笑。
- 本项目独立运行，不依赖 AI Hero Detector，也不自动调用它打分。
- 使用在线助手时，输入由该助手处理；项目本身不主动上传或保存素材。
